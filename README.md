# オンライン大喜利

友達（2〜10人）とDiscordなどで通話しながら遊ぶ、ブラウザだけで動く大喜利アプリです。
サーバーはいりません。MC（司会）のブラウザが「部屋の親」になり、参加者はインターネット経由で直接つながります。

- **MC画面**: お題を出す・フリップを公開する・タイマー・効果音（SE）
- **参加者画面**: スマホでもPCでも、手書き or 文字で回答を書いて提出・挙手
- **ステージ画面**: OBSに取り込んで配信に映すための画面（1920×1080）

---

## 1. 遊び方

### MC（司会）
1. 公開したURL（例: `https://あなたの名前.github.io/ogiri/`）を開く
2. 「**部屋を作る（MC）**」を押す → 画面左上に **部屋コード（4文字）** が出ます
3. 「**参加用URLをコピー**」を押して、Discordのチャットに貼って友達に送る
4. お題を入力して「**出題**」（またはお題リストから「🎲 ランダム出題」）
5. 必要ならシンキングタイマーを「スタート」。0秒で「ジャン」が鳴ります
6. 参加者カードの「**公開**」でフリップをめくる。「**全部公開**」で一気にめくる
7. 面白い回答は「**スポットライト**」でステージに大きく表示（もう一度押すと解除）
8. 次のお題に行くときは「**全部クリア（次の回へ）**」で全員のフリップが白紙に戻ります

- SEパッドのボタンで効果音が全員の画面で鳴ります。「＋ mp3を追加」で自分の音も追加できます（次回も残ります）
  - 追加したボタンは **長押し** か **×** で削除、**✎** で名前変更
  - 1.5MBを超える音はネットで送らず、MCとステージ画面でだけ鳴ります
- MC画面をリロードしても同じ部屋コードで復活します（同じタブの場合）。参加者は自動でつながり直します
- MCのタブを閉じると部屋はなくなります。遊んでいる間は閉じないでください

### 参加者
1. MCから送られたURLを開く（部屋コードが入った状態で開きます）
2. 名前を入れて「**入室する**」（名前は次回も覚えています）
3. 「✏️ 手書き」か「🔤 文字」を選んで回答を書く
   - 手書き: ペン色（黒・赤・青）、太さ3段階、消しゴム、戻す、全消し
   - 文字: 入力するとフリップに大きく表示されます（長いと自動で小さくなります）
4. 書けたら「**提出する**」。直したいときは「**書き直す**」
5. 答えたいときは「**✋ 挙手**」（もう一度押すと取り下げ）
- 画面上の名前をタップすると名前を変えられます
- 回線が切れても3秒ごとに自動で再接続します（書いた内容は残ります）

### 配信（OBS）に映す
1. MC画面の「**ステージURLをコピー**」を押す
2. OBSで「ソース」の「＋」→「**ブラウザ**」を追加
3. URL欄に貼り付け、**幅 1920 / 高さ 1080** に設定して OK
4. 背景を透過させたいときは URL の最後に `&chroma=1` を付けて緑背景にし、OBSで「クロマキー」フィルタをかけます
5. MCと同じPCでMC画面の音もOBSに入っている場合、SEが二重に聞こえるのを防ぐには URL に `&mute=1` を付けます

### URLパラメータ一覧

| 例 | 意味 |
|---|---|
| `?room=AB7K` | 部屋コード入りの参加画面を開く |
| `?room=AB7K&stage=1` | ステージ画面（配信用）を開く |
| `&chroma=1` | ステージの背景を緑（`#00FF00`）にする（クロマキー用） |
| `&mute=1` | ステージではSEを鳴らさない |
| `?host=1` | MC画面（リロード用。自動で付きます） |

## 3. 自分のパソコンで動作確認する

このアプリは `index.html` をダブルクリック（`file://`）で開いても**動きません**。
小さなWebサーバーを使って `http://` で開きます。

1. [Node.js](https://nodejs.org/ja) をインストール（「LTS」と書いてある方でOK）
2. エクスプローラーで `ogiri` フォルダを開き、上のアドレスバーに `cmd` と入力して Enter（黒い画面が開きます）
3. 次の1行を入力して Enter

   ```
   npx --yes http-server . -p 8790
   ```

4. ブラウザで `http://localhost:8790/` を開く
5. タブを3つ開けば、1人で「MC」「参加者」「ステージ」を試せます
   - 1つ目のタブで「部屋を作る（MC）」
   - 2つ目のタブに「参加用URL」を貼って入室
   - 3つ目のタブに「ステージURL」を貼る
   - 参加者を2人以上試したいときは、2人目以降を **別のブラウザ**（Chrome と Edge など）か **シークレットウィンドウ** で開いてください（同じブラウザの普通のタブ同士は同じ人として扱われます）
6. 終わるときは黒い画面で Ctrl+C

※ スマホからパソコンの `localhost` は見えません。スマホで試すときは GitHub Pages に公開したURLを使ってください。

## 4. つながらない時のヒント

- **部屋コードが合っているか**: 大文字4文字。MC画面の左上に出ているコードと同じか確認
- **MCのタブが開いたままか**: MCのタブを閉じる・PCがスリープすると部屋が消えます
- **ブラウザ**: Chrome / Edge / Safari（iPhone）/ Android の Chrome を使ってください。アプリ内ブラウザ（LINEやDiscordの中で開いたページ）ではうまく動かないことがあります。右上メニューの「ブラウザで開く」を使ってください
- **会社・学校のネットワーク**: 直接つながれない回線では、無料の中継サーバー（TURN: openrelay.metered.ca）を経由します。混んでいると遅くなったりつながらなかったりします。スマホならWi-Fiを切ってモバイル回線にすると直ることがあります
- **「部屋が見つかりません」と出続ける**: MC側で「受付中」になっているか確認。MCがリロードして部屋コードが変わっていたら、新しい参加用URLを送り直してください
- **SEが鳴らない**: 画面を一度タップ／クリックしてください（ブラウザの仕様で、操作するまで音が出せません）。スマホのマナーモードも確認
- **OBSで音が出ない**: ブラウザソースの設定で「OBSで音声を制御する」をオンにして、音声ミキサーに出てくるか確認
- それでもダメなときは、全員ページを再読み込みしてみてください（参加者の書いた内容は再接続で戻ります）
